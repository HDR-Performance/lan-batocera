Fetch Missing Artwork

Downloads matching box art from the community-maintained Libretro Thumbnails catalog. Existing artwork is never replaced. Matches depend on the ROM filename, and Batocera's game list is backed up before it is updated.

Arcade Themes

Choose a built-in theme or build your own. Themes are saved only in this browser.

Controller Layout

Touch controls appear automatically on phones when no physical preset is selected. For a Bluetooth or USB controller, choose the labels printed on it. The choice is saved in this browser and applied before each game starts.

Experimental Multiplayer

Player 1 names and creates a LAN lobby by choosing a game. Player 2 or 3 selects that open lobby and automatically loads the same synchronized game with a separate controller slot.
